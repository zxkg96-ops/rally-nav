# RALLY NAV

Android-навигатор с голосом раллийного штурмана. Тёмный интерфейс, крупная стрелка,
короткие команды: «Через 400 метров поворот направо», «Направо».

**Состояние:** код написан полностью, но в момент создания он НЕ собирался и НЕ запускался
(в среде автора не было Android SDK и интернета). Первая сборка в GitHub Actions покажет,
есть ли ошибки. Присылай лог, я быстро поправлю.

## Что внутри

| Часть | Что делает |
|---|---|
| `NavEngine` | Положение на маршруте, следующий манёвр, отклонение, защита от скачков GPS |
| `AnnouncementPlanner`, `Phrases` | Когда и что говорить (по скорости, без ИИ) |
| `VoiceNavigator` | Очередь фраз, приоритеты, защита от повторов, Android TextToSpeech |
| `ValhallaClient`, `NominatimClient` | Маршрут и поиск адреса (бесплатные публичные серверы OSM) |
| `MapPanel` | Карта MapLibre, тёмный стиль, линия маршрута, твоё положение |
| `NavigationService` | Держит GPS и голос при заблокированном экране |

## Как собрать (без компьютера)

1. На github.com создай **публичный** репозиторий `rally-nav`.
2. В Termux:
   ```
   pkg install git unzip
   unzip rally-nav.zip && cd rally-nav
   git init && git add . && git commit -m "RALLY NAV"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ-НИК/rally-nav.git
   git push -u origin main
   ```
   Пароль для push — это токен: github.com → Settings → Developer settings →
   Personal access tokens (право `repo`).
3. На GitHub открой вкладку **Actions**. Сборка идёт 5–10 минут.
4. Когда она зелёная, открой запуск и скачай **rally-nav-debug-apk** (внутри `app-debug.apk`).
5. Установи APK на телефон (разреши установку из этого источника).

Перед сборкой в `app/src/main/java/app/rallynav/Net.kt` замени `ЗАМЕНИ-НА-СВОЙ-НИК`
в `USER_AGENT` на свой ник GitHub. Серверы OSM требуют, чтобы приложение представлялось.

## Известные ограничения

- Нужен интернет: карта, поиск и маршрут приходят с серверов. Офлайна нет.
  Построенный маршрут без интернета продолжает озвучиваться по GPS, но перестроить его нельзя.
- Публичные серверы Valhalla и Nominatim годятся для разработки и личного использования.
  Для выпуска нужен свой сервер или платный провайдер.
- Русский голос должен быть установлен в телефоне (Настройки, Синтез речи).
- Минимальный Android: 11.
- Приложение не оценивает крутизну поворотов и не советует скорость. Подсказки строятся
  только из типа манёвра, который вернул сервер.
- Приложение не находит опасности на дороге и не заменяет внимание водителя.

## Проверка

Автотесты (запускаются в Actions после сборки): нормальная езда, повтор GPS, скачок GPS,
неточный GPS, отклонение и возврат на маршрут, дрожание GPS без повторов фраз, два близких
поворота, прибытие, пороги по скорости, фразы, разбор ответа Valhalla.

Вручную проверь (в автотесты это не входит):
1. Запрет геолокации: появляется кнопка «Разрешить», навигация не стартует.
2. Нет русского голоса: появляется жёлтая плашка с кнопкой «Речь».
3. Режим полёта при построении маршрута: понятное сообщение об ошибке.
4. Режим полёта во время движения: подсказки идут, при съезде появляется «Не могу перестроить».
5. Блокировка экрана и сворачивание: голос продолжает говорить.
6. Закрыть приложение во время навигации: при запуске кнопка «Продолжить к …».
7. Сначала в машине как пассажир или пешком. На дороге водитель не смотрит в телефон.
